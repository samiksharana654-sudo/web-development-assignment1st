MY WEB DEVELOPMENT JOURNEY

Site Report

My experience of learning web development and creating my portfolio website.

My Experience

At the beginning of this module, I had a basic understanding of websites, but I was not very confident with writing HTML and CSS myself. As I started learning, I slowly became more comfortable with creating web pages and understanding how different elements work together.

HTML was one of the first things I focused on. I learned how to structure a webpage using headings, paragraphs, images, links, lists, tables and forms. I also learned that using the correct semantic elements is important. For example, I used nav, header, main and footer instead of using div elements for everything.

CSS was more challenging for me at first. I had to learn how spacing, fonts, grids and responsive layouts work. I experimented with different layouts before deciding on a simple design with a light background, white content areas and purple highlights. I wanted the website to look clean without making it too complicated.

One thing I found difficult was making the website responsive. Some layouts looked good on my computer but did not look as good on a smaller screen. I used CSS media queries to change the layout for smaller devices. This helped me understand why responsive design is important.

I also used Git and GitHub to manage my work. Making regular commits helped me keep track of the changes I made during development. Sometimes I made mistakes in my code and had to go back, check the problem and fix it. Although debugging was sometimes frustrating, it helped me understand my code better.

Design Decisions

I chose a simple and modern design for my portfolio. I used Arial as the main font because it is easy to read. I used purple as the main highlight colour because it gives the website some personality while keeping the overall design simple.

I also decided to use the same navigation and CSS throughout the website. This makes the pages feel connected and makes it easier for visitors to move around the portfolio.

Reflection

Overall, this module has helped me become more confident with web development. I learned that creating a website is not only about making it look good. It is also about structure, accessibility, responsiveness, testing and keeping the code organised.

There were times when I found the work difficult, especially when fixing CSS problems or trying to make different pages look consistent. However, solving these problems was also one of the most useful parts of the module. I now feel more confident about creating and improving websites independently.
